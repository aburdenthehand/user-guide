# Contributing to KubeVirt

The KubeVirt project welcomes contributions to code, documentation, and community efforts.

## Full contributing guide

See [Contributing to KubeVirt](../contributing.md) for:

- Prerequisites (Git, GitHub workflow, golang knowledge for code contributions)
- Finding your first issue (good-first-issue labels)
- Community membership and growth paths
- Code of conduct and governance
- AI contribution policy

## Quick links

- **Getting started with open source**: [CNCF contributor getting started guide](https://contribute.cncf.io/contributors/getting-started/)
- **Code contributors**: [kubevirt/kubevirt CONTRIBUTING.md](https://github.com/kubevirt/kubevirt/blob/main/CONTRIBUTING.md) — core project contribution workflow
- **Docs contributors**: [kubevirt/user-guide repository](https://github.com/kubevirt/user-guide) — this documentation site's source
- **Storage (CDI) contributors**: [kubevirt/containerized-data-importer](https://github.com/kubevirt/containerized-data-importer/tree/main)
- **Good first issues**: Filter by [`good-first-issue` label](https://github.com/kubevirt/kubevirt/issues?q=is%3Aopen+is%3Aissue+label%3Agood-first-issue) in the main repository

## Community

- **Slack**: Join `#virtualization` on [Kubernetes Slack](https://kubernetes.slack.com/messages/virtualization)
- **Mailing list**: [kubevirt-dev Google Group](https://groups.google.com/forum/#!forum/kubevirt-dev)
- **Community page**: [kubevirt.io/community](https://kubevirt.io/community/) for meetups, events, and social media

## Try KubeVirt first

If you're new to KubeVirt, try one of the interactive labs before contributing:

- [Killercoda interactive scenarios](https://killercoda.com/kubevirt)
- [KubeVirt Labs](https://kubevirt.io/labs/kubernetes/lab1.html) — Use KubeVirt, CDI experiments, upgrades, live migration
